# Multiplicity

Companion repository with scripts for the paper:

> González-Casabianca F, Dulya O, Flores-Almaraz V, Tedersoo L,
> Mikryukov V. 2026. Multiplicity Quantifies Intra-Cluster Diversity in
> Metagenomic Analysis. Environmental DNA 8, no. 6: e70389.
> [DOI:10.1002/edn3.70389](https://onlinelibrary.wiley.com/doi/10.1002/edn3.70389)

For replicability of the results, please use the branch `first-paper-legacy-version` of the [divermeta](https://github.com/Mycology-Microbiology-Center/divermeta/tree/first-paper-legacy-version) library.
